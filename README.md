# tiny-chess

A chess engine in 4 KB of Python: alpha-beta search with iterative deepening, quiescence, a transposition table, null-move pruning, late-move reductions and piece-square tables. It plays the make.fun gauntlet through the env at MAKEFUN_ENV_URL, one fixed node budget per move, no clock and no unseeded randomness.

## Run it

```sh
python3 main.py
```
